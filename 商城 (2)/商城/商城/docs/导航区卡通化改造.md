## 二、本轮：把导航区做得明显「卡通」

上一轮偏「干净规整」，这一轮按你的意思往**卡通贴纸**方向加大力度。

### 1. 顶部导航栏 → 圆角"贴纸头"

| 改动前 | 改动后 |
|---|---|
| 通栏 + 底部一条深棕线 | **左右也加描边 + 底部圆角 32rpx**，像贴在屏幕顶部的一张圆角贴纸 |

覆盖全部 **21 个使用导航栏组件的页面**（改组件一处即可）。

### 2. 分类宫格 → 糖果色 + 倾斜贴纸

| 改动前 | 改动后 |
|---|---|
| 10 个格子统一浅橙底 | **每个分类一个糖果色**，并**交替轻微倾斜（±2~3°）**，像随手贴上去的贴纸 |

配色（按分类顺序）：`#FFD8A8` 奶黄 / `#BFE6F5` 天蓝 / `#FFC7BE` 珊瑚粉 / `#D8ECB4` 嫩绿 /
`#D7CDF5` 薰衣草 / `#FFE0B8` 蜜橙 / `#C9E4F7` 湖蓝 / `#FFD3E0` 樱粉 / `#CDEBD8` 薄荷 / `#E4DAFA` 淡紫

同时应用于**首页宫格**与**分类页左侧导航**。

### 3. 「我的」页订单四宫格 → 糖果色 + 倾斜

待确认 `#FFD8A8` / 待见面 `#BFE6F5` / 已完成 `#CDEBD8` / 我卖出的 `#FFD3E0`，
每个加 4rpx 深棕描边并轻微倾斜。

### 4. 底部 tabBar → 圆角条 + 选中气泡 + 弹跳

| 改动前 | 改动后 |
|---|---|
| 直边 + 顶部一条线；选中项是"药丸底" | **顶部两角圆角 32rpx**（圆角贴纸条）；选中项的图标**落进一个珊瑚色圆气泡**里；切换时**弹跳动画**（`cubic-bezier(.34,1.56,.64,1)` 回弹） |

气泡是这一轮卡通化的关键——比原来的药丸底更像"图标坐在一个小球上"。

## 三、技术记录

**WXSS 支持 `:nth-child`（实测有效）**。所以「每个格子不同颜色 + 交替倾斜」不需要改 JS 数据、
也不需要动 wxml，纯 CSS 就能做：

```css
.cat-item:nth-child(1) .cat-icon { background: #FFD8A8; transform: rotate(-3deg); }
.cat-item:nth-child(2) .cat-icon { background: #BFE6F5; transform: rotate(2.5deg); }
/* …共 10 条 */
```

这比在云函数里加颜色字段、或在页面 JS 里做映射都省事，且**零数据迁移**。
