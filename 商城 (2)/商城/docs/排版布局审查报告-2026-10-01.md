# 校园集市 · 全页面排版布局审查报告

- 日期：2026-10-01 ｜ 范围：26 个页面 + 3 个组件 + custom-tab-bar
- 方式：对照 `app.wxss` 设计令牌，逐页静态审查 `.wxml` / `.wxss`（含 5 处关键结论人工复核）。
- 总体印象：**整体版式是健康的** —— 自定义 tabBar 避让、安全区、长文本兜底在关键页都已到位；问题主要分两类：① 少数「结构级」缺陷（空态误闪、底栏常驻、定位父级缺失）；② 大量「令牌漂移」类一致性问题（字号/间距/圆角/杂色）。

---

## 一、结构级问题（优先处理）

1. **订单详情 · 底部操作栏无条件常驻** —— [`pages/order-detail/order-detail.wxml:97`] `.bottom-bar` 本身没有 `wx:if`，只有内部按钮各自带条件；当订单「已完成且双方都已评价」或「已取消」时所有按钮都不命中 → 屏幕底部留下**一条只有顶边线的空白白条**。→ 无可用操作时应整体隐藏底栏。
2. **订单列表 · 空态误闪** —— [`pages/order/order.wxml:67-109`] 分支是 `wx:if list.length → wx:elif loadError → wx:else(空态)`，加载提示写在 `list.length` 分支内部；首屏 `list` 为空且 `loading=true` 时会直接落进空态、显示「还没有订单」。→ 外层应先判 `loading`。
3. **订单列表 · 底部按钮未占满** —— [`pages/order/order.wxss:34-38`] 底栏缺少 `.btn{flex:1}`（全局只给 `.fixed-bottom .btn` 写了），唯一按钮「提交订单」按内容宽度左对齐；而同结构的订单详情底栏是占满的 → 两页操作条对齐不一致。
4. **商品详情 · 图片指示器定位无父级** —— [`pages/detail/detail.wxss:2` 与 `:16-17`] `.hero` 没有 `position:relative`，而 `.hero-indicator` 是 `absolute; top:580rpx` → 计数器位置依赖「hero 恰好在首屏顶部 + 导航栏固定高度」的巧合，导航栏高度或滚动位置一变就错位。→ 让 `.hero` 成为定位父级。
5. **信用分 · 未定义类导致无间距** —— [`pages/credit/credit.wxml:39`] 用了 `mt-4`，而全局只定义了 `mt-8/16/24/32` → 规则描述**完全没有上间距**，紧贴上方标题。→ 改用 `mt-8`。
6. **学生认证 · 输入框没有框** —— [`pages/verify/verify.wxss:16`] `.ipt` 只有 flex / 字号 / 省略，**没有白底、描边、圆角、内边距**（这些在全局 `.input` 里）→ 整页表单输入退化成"无边框"，与全站输入框风格不一致。→ 补齐令牌或复用 `.input`。
7. **订单列表 · 商品封面会被压扁** —— [`pages/order/order.wxss:20`] `.cover` 给了固定 180rpx 但**没有 `flex-shrink:0`**，处在 flex 行内；标题变长时封面被压缩变形（订单详情的同名封面有 `flex-shrink:0`）。→ 补 `flex-shrink:0`。

## 二、长文本溢出风险（后台页为主）

8. **审核中心** —— [`admin-reviews.wxml:77` 举报描述] [` :117` 反馈内容] [` :72` 被举报人 `targetId`（openid 长串）] [` :118` 联系方式] 均**无 `word-break` / 省略**，用户填的长描述或长串会横向撑破卡片；[`:54` 举报人昵称] 在 `flex-between` 左端且无 `ellipsis`，超长会与右侧状态标签重叠。
9. **订单详情** —— [`order-detail.wxml:30-33` 商品描述] [` :45-49` 买家留言] [` :9` 取消原因] 无截断或换行，超长内容会把卡片撑高 / 顶满一行。
10. **管理后台首页** —— [`admin.wxss:64`] 审计日志 `.log-target` 既无 `ellipsis` 也无 `word-break`，且前缀写死 `…`，长目标串会撑破。
11. **会话列表** —— [`chat.wxml:8`] 昵称无 `.ellipsis`、其父 flex 组无 `min-width:0`，超长昵称会把右侧时间挤出版心。
12. **个人主页** —— [`sold.wxml:10-13`] 卖家昵称无省略、与认证标签同行，长昵称会挤压标签。

## 三、设计令牌违例（描边 / 阴影 / 杂色）

13. **商品卡片组件（index/category/search/favorite 共用，影响面最大）** —— [`components/goods-card/goods-card.wxss:54`] `.gc-report` 用了 `box-shadow: 0 2rpx 6rpx rgba(0,0,0,.18)`，直接违反「不用阴影」的令牌；[`:39`] `.gc-badge` 用青蓝 `rgba(46,196,182,.95)`，与详情页同语义的 `.tag-success` 绿不一致；[`:45`] `.gc-badge-want` 背景硬编码 `#e8542f`。
14. **商品详情 · 提示卡整卡换色** —— [`detail.wxss:25`] `.notice` 把四边描边都改成珊瑚 `--primary`，与同页其它卡片的深棕描边冲突，且左 8rpx 与右/下 8rpx 混用不对称。
15. **发布页 · 价格用错色** —— [`publish.wxss:68`] `.price-input input` 用 `var(--danger)` 红，与「价格 = 珊瑚橙」冲突。
16. **登录页 · 主按钮脱离按钮系统** —— [`login.wxss:24-28`] 本页覆写 `.btn{border-radius:16rpx}` 且 `.btn-primary` **缺右下 8rpx 翘边** → 既非全圆角、也无贴纸翘边。
17. **后台三页 · 小按钮各自为政** —— `admin-goods` / `admin-users` / `admin-reviews` 都重写了 `.btn-sm` 为「30rpx 胶囊 + 1~2rpx 浅灰描边」，与全局 `.btn-sm`（16rpx 圆角 + 3rpx 深棕描边）完全不同，且三页之间描边宽度 1rpx / 2rpx 还不统一。
18. **信用分 · 大圆缺描边** —— [`credit.wxss:2-7`] `.score-ring` 绿色大圆没有深棕描边，违背「描边代替阴影」。
19. **胶囊类控件缺描边** —— [`feedback.wxss:5-8`] `.kind`、[`sold.wxss:82-93`] `.cat` 用浅底但**无深棕描边**，与 `.seg`（白底 + 3rpx 描边）不一致；[`verify.wxss:96-97`] 与 [`login.wxss:121`] 的勾选框是「圆形 + `#d8c6aa` 2rpx」。
20. **空态组件绕开按钮系统** —— [`components/empty/empty.wxml:6,9`] 操作按钮用内联 `height:64rpx / font-size:26rpx / radius:32rpx`，与全局 `.btn`（88rpx / 30rpx / 44rpx）完全脱节。
21. **卡片白底规则被破** —— [`order-detail.wxss:5`] `.status` 卡改成奶油底 `#fff9ee`，与其余白底卡片不一致（且硬编码而非 `var(--bg)`）。
22. **硬编码杂色** —— `admin-reviews` 的 danger 红 `#f5222d`、`admin-goods/users` 的 warn 橙 `#C7860B`、`agreement/privacy` 正文 `#6b543f`、`search .chip.price-apply` 与 `goods-card .gc-badge-want` 的 `#e8542f`，都没走令牌。

## 四、字号与间距节奏漂移

23. **零碎字号**（不在 24/28/32/36/44 档）：index `.banner-title` 40、detail `.notice-desc` 23 / `.notice-row` 25、order-detail `.status-text` 40、credit `.score-num` 56 / `.stars` 26、admin 多处 21/22/27/34/38、admin-goods `.issue-row` 25、admin-users 23/25、admin-reviews 25/23/26/22、edit-profile 30/26、login 26/34/30、sold 34、mine 箭头 48、chat/sold 认证标签内联 20、goods-card `.gc-title` 26。
24. **零碎间距**（非 8 倍数）：index `.school-tip` 20 + 内联 12、category 12/6、publish 230、chat `.conv-item padding` 20、chatroom 6、credit gap 20 / padding 20、admin 22/18/2/14、admin-goods 20/10/12/14、admin-users 18/10/14、admin-reviews 12/6、edit-profile 28、verify `.label` 180 / 28、sold 20/10/6、empty padding 100、agreement·privacy 落款 60。
25. **零碎圆角**：index `.banner` 24、login `.sheet` 32、nav-bar 32、edit-profile `.avatar` 16、verify 12。

## 五、跨页一致性

26. 商品封面：`order` 180rpx vs `order-detail` 160rpx；底部占位 160rpx vs 200rpx。
27. 后台「异常信息块」两套皮肤：`admin-goods`/`admin-users` 用 `.issue`（`#FFF8F6` + 左 8rpx），`admin-reviews` 用 `.trail`（`#F7F4EC`）。
28. 后台四页「一张卡 = 一条记录」的 6 层架构不平行：`admin-users` 把关联行合并、用顶部分隔线；`admin-reviews` 的认证/举报/反馈三种卡骨架各异。
29. 同类次要信息字号不一致：admin-goods 页脚 22 / admin-users 数据行 23 / admin-reviews 轨迹 25、23。
30. 认证标签被内联覆写（`font-size:20rpx;padding:2rpx 10rpx`）出现在 `chat` 与 `sold` 两页，与 `.tag` 令牌（22rpx / 4rpx 14rpx）不符。
31. 「添加图片」控件：`report` 用 `2rpx dashed #d8c6aa` + 删除按钮 40rpx，`publish` 用 `3rpx dashed var(--ink)` + 44rpx → 同角色控件不一致。

## 六、其它细节

32. `order`：[`order.wxml:3-7`] 标签栏 `position:sticky; top:0`，而 `nav-bar` 是 `relative`（会滚走）→ 刘海屏上标签会顶到状态栏下方被压住。
33. `mine`：[`mine.wxss:9`] `.header-bg` 写死 `height:380rpx`，字号或机型变化时橙底可能盖不满 / 露白带。
34. `sold`：[`sold.wxss:57-64`] `.tab` 同时设 `margin:10rpx 6rpx` 与父 `.tabs{gap:8rpx}`，水平间距叠加成 14rpx，内外节奏不一致。
35. `index`：[`index.wxss:79`] `.section-head` 用 `align-items:baseline`，右侧小字会与左侧 60rpx 胶囊做基线对齐，视觉上像被压到底部。
36. `chat`：[`chat.wxss:7`] `.conv-item` 用 `padding:20rpx` 覆写 `.card` 的 24rpx。
