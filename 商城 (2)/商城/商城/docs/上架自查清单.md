## 二、需要你操作（微信后台，约 20 分钟）

### 2.1 配置《用户隐私保护指引》——必做，优先级最高

> 不做，提审会被拒；做了，下面的微信隐私校验开关才能安全启用。

**路径**（微信后台改版过，三条都试一下）：
- **首选**：左侧「管理」→ 「**账号设置**」→ 找「**用户隐私保护指引**」（或「服务内容声明」「隐私设置」）
- 备选：左侧「**设置**」（跟「管理」平级的一级菜单，可能被滚条挡住）→「第三方设置」→「用户隐私保护指引」
- 备选：顶部「小程序」标题右侧的齿轮⚙️

**要勾选的采集类型**（照抄即可，与我们的隐私政策一一对应）：

| 采集类型 | 具体字段 | 用途 |
|---|---|---|
| 用户信息 | 微信昵称、头像 | 在商品页、聊天中展示 |
| 身份信息 | 真实姓名、学号、学校、学历、学信网学籍证明截图 | 核实是否为该校在校学生 |
| 位置信息 | 自提点坐标 | 仅在你自定义自提点选点时获取 |
| 相册 / 文件 | 商品图片、认证截图、聊天图片 | 发布商品、学生认证、沟通 |

**第三方 SDK**：选「无」或跳过（本项目只用微信云开发，不接广告/统计/支付）。

填完点「提交」，通常即时生效。

### 2.2 服务类目

「设置」→「基本设置」→「服务类目」→ 添加：
- 推荐：**工具 → 信息查询**，或 **教育 → 校园服务**
- ⚠️ **不要选**电商、交易平台、二手交易类目——个人主体选了必被拒，且需要 ICP 证

### 2.3 开通内容安全

云开发控制台 →「扩展能力 / 安全」→ 开通「内容安全」。
不开的话 `seccheck` 云函数会降级放行，UGC 等于没有防护。

### 2.4 部署云函数

微信开发者工具 → 右键各云函数目录 →「上传并部署：云端安装依赖」。
必传清单：`user`（本轮改过）、`goods`、`order`、`chat`、`school`（含 `schools.json`）、`admin`、`feedback`、`seccheck`、`login`。

### 2.5 提审信息

- **简介 / 关键词**：去掉「交易、买卖、支付、二手交易」字眼，改成「校园闲置物品信息共享、同校同学线下自提」
- **测试账号**：在提审备注里给审核员两个账号
  - 已认证账号（能完整体验发布、预约、聊天）
  - 未认证账号（能看到认证引导）
  并写明体验路径，否则容易被「无法体验完整功能」打回

## 三、配好隐私指引后，再启用微信隐私校验（这一步我来改）

当前状态：**`__usePrivacyCheck__` 已关闭**（为避免你在后台配好指引前，头像/昵称/选图被静默拦截）。

等你完成 2.1 后，跟我说一声「隐私指引配好了」，我会做两处改动：

1. `app.json` 加回 `"__usePrivacyCheck__": true`
2. `app.js` 加回 `_initPrivacy()`：注册 `wx.onNeedPrivacyAuthorization`，
   在首次触发头像/相册/位置接口时弹统一授权弹窗

改完请你在真机上验证这 4 个点，全部能弹出授权弹窗并正常进入功能即算通过：
- 登录页点头像
- 发布页点添加图片
- 认证页点添加截图
- 自提点页点自定义位置

**回滚预案**：若真机发现选图异常，把 `app.json` 的 `"__usePrivacyCheck__"` 改成 `false`，一行回退。

## 四、真机验收路径（提审前自己走一遍）

用**体验版**在手机上完整跑：

1. 登录 → 勾选协议 → 选头像/昵称 → 授权并登录
2. 我的 → 学生认证 → 填信息 → 上传学信网截图 → 勾选同意 → 提交
3. 管理员通过认证（用 admin 页）
4. 发布商品（填标题/价格/分类/成色/自提点/图片）
5. 回首页确认能看到自己发的商品（**按校区过滤，学校必须匹配**）
6. 换一个账号浏览该商品 → 私聊 → 预约自提
7. 卖家接受 → 双方标记完成 → 互评

任何一步卡住，先看调试器 Console 红字，再对照下面的常见原因：

| 现象 | 最常见原因 |
|---|---|
| 首页空白 / 商品全无 | 云函数未部署，或用户学校与商品 `campus` 不一致 |
| 发布失败 | 未认证，或 `school` 云函数没部署 |
| 商品卡显示旧学校 | `user` 云函数未部署（存量同步在 `me` 里） |
| 图片裂图 | 收藏页/详情页走的是 `cloud://` 未转 https（已修，需部署 `user`） |
| 选图/选头像无反应 | `__usePrivacyCheck__` 已开但 mp 后台隐私指引没配（见第三节） |
