# 按钮样式规范（手绘贴纸风）

> 本文是小程序内**所有「按键」的统一规范**。新增按钮时照本文选变体即可，
> 不要再在页面里另写一套颜色/圆角/描边。

---

## 一、统一要素（所有按钮必须一致）

| 要素 | 规范 | 说明 |
|---|---|---|
| **描边** | 深棕 `--ink`（#3D2B1F） | 大按钮 4rpx，右下加粗到 8rpx 做出「贴纸翘边」；小按钮统一 3rpx |
| **圆角** | 大按钮 44rpx（全圆角）/ 小按钮 16rpx / 选择器 30rpx | 同一层级必须同一半径 |
| **字体** | 大按钮 30rpx / 小按钮 24rpx / 选择器 26rpx，全部 `font-weight: 500`、`line-height: 1` | 用 `flex` 垂直居中，不再用 `line-height` 撑高度 |
| **主色** | 珊瑚橙 `--primary`（#E8542F） | 白字；主色**只**用于主按钮 / 选中态 / 价格 |
| **浅色** | `--primary-light`（#FFE3D6）+ `--primary-dark` 字 | 弱操作 |
| **禁用** | 底 `#F0D6C8`、描边 `#C9B49A`，并**去掉翘边** | 视觉上"瘪"下去，与可点状态区分 |
| **间距** | 内边距：大按钮 `0 40rpx`、小按钮 `0 26rpx`、选择器 `0 28rpx`；相邻按钮 `gap: 16rpx` | |
| **按压动效** | **翘边收平 + 位移 4rpx**（`translate(4rpx,4rpx)`），`transition: .08s` | 模拟"把贴纸按平"，全站统一 |

### 按压反馈怎么加（重要）

小程序里 `view` 的按压反馈**必须靠 `hover-class`**，`view` 的 `:active` 不完全可靠。

```xml
<view class="btn btn-primary" bindtap="submit" hover-class="press" hover-stay-time="80">发布</view>
```

- `press` 已在 `app.wxss` 全局定义，**直接用**；
- 图标类按钮（无翘边）用 `press-scale`（缩放 0.94），避免位移显得"跑偏"。
- 原生 `<button>` 用 `:active` 兜底（已在全局写好）。

## 二、按钮变体（共 6 类，覆盖全部场景）

| 变体 | 样式 | 用在哪 |
|---|---|---|
| `.btn.btn-primary` | 珊瑚实底 + 白字 + 翘边 | 主操作：发布、提交、立即购买 |
| `.btn.btn-ghost` | 白底 + 珊瑚字 + 翘边 | 次操作：我要买、取消 |
| `.btn.btn-line` | 浅珊瑚底 + 深珊瑚字 | 弱操作 |
| `.btn-sm` （+.btn-primary/.btn-ghost/.btn-line/.btn-danger） | 高度 60rpx、圆角 16rpx、白底描边款为默认 | **列表内小操作**（下架/删除/联系卖家/通过上架），共 24 处 |
| `.btn-mini` （+.btn-mini-light） | 与 `.btn-sm` 同视觉，`flex:1` 等分宽度 | 卡片底部并排小按钮 |
| `.seg` / `.seg.on` | 未选：白底 + 深棕描边 + 深棕字；选：珊瑚实底白字 + **保留深棕描边** | 单选控件通用件 |

> ⚠️ 选中态**必须保留深棕描边**（不是改成珊瑚色描边）—— 这是贴纸风的关键，改了会失去轮廓。

---

## 三、选择器（单选控件）统一后的样子

原本全站有 7 套互不一致的选择器样式（有的无描边、有的用下划线、有的选中态是浅底），现已统一为同一套：
**未选中 = 白底 + 3rpx 深棕描边 + 26rpx 深棕字；选中 = 珊瑚实底 + 白字 + 深棕描边；统一高度 60rpx、全圆角。**

| 页面 | 类名 | 改造前的问题 |
|---|---|---|
| 搜索页筛选 | `.chip` / `.chip.on` | 内边距 8rpx/22rpx，与他人不一致 |
| 发布页分类 | `.cat-pill` / `.active` | 内边距 12rpx/24rpx，圆角 30 vs 28 混用 |
| 评价页标签 | `.tag-pill` / `.active` | **完全没有描边** |
| 审核中心分段 | `.seg-item` / `.on` | **无描边**，且选中态是浅底而非实底 |
| 首页 闲置/求购 | `.type-switch-item` / `.active` | 选中态是白底珊瑚字（与其他"选中=实底"相反） |
| 发布页 出售/求购 | `.type-tab` / `.active` | 圆角仅 12rpx，且无描边 |
| 分类页排序栏 | `.filter-item` / `.active` | 用**下划线**指示，与全站"药丸"语言不符 |
| 我的商品 tab | `.tab` | 无描边、圆角 12rpx |
| 管理后台 tab | `.tab` / `.tab.on`（4 个页面） | **无描边**；容器是白槽，与白药丸糊在一起 → 容器改为「暖色描边槽」 |
| 聊天页表情分组 | `.emoji-tab` | 无描边 |
| 聊天页发送 | `.send-btn` | 无描边、无圆角统一 |

## 四、图标按钮

统一为「**描边贴纸底托**」，与首页分类宫格 / tabBar 图标同一视觉：
白色底 + 3rpx 深棕描边 + 大圆角 + `press-scale` 缩放反馈。

| 位置 | 改造 |
|---|---|
| 首页分类宫格 `.cat-icon` | 已统一（10 个 emoji 加底托） |
| 分类页左侧 `.left-icon` | 已统一 |
| **「我的」页订单四宫格** `.order-cell .emoji` | **裸 emoji → 加白色描边底托**（本次新增） |
| 聊天页 `.icon-btn` | 裸图标 → 圆形白底 + 描边 |
| 发布页 `.image-add` | 灰色虚线 → 白色底 + 深棕虚线描边 |
| 发布页 `.image-remove` | 半透明黑圆 → 加深棕描边 |
