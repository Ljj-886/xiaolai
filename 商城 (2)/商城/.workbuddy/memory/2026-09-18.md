## 导航栏手绘卡通气泡配色（Request C）

用户要求：导航栏每个格子背景改为手绘卡通风、柔亮+笔触质感，且底色必须与图标强对比（不同色/不相近）。

### 做法
- 用 Pillow 实测 10 张图标真实像素色，确定图标只有三色：未选中 `#806050`(暖棕)+`#F0E0D0`(奶油)；
  选中 `#302010`(近黑)+`#E05020`(珊瑚橙)。据此选 5 种"避开棕/奶油/珊瑚橙且足够亮"的 pastel：
  首页薄荷绿 `#D9F2E5` / 分类天空蓝 `#CFE8FF` / 发布薰衣草紫 `#E9DDFF` / 消息柠檬黄 `#FFF3C2` / 我的水鸭青 `#C9EFE8`。
- 改 3 文件：`custom-tab-bar/index.js`（list 每项加 `bg` 字段）、`index.wxml`（图标外包 `.tab-chip`
  内联 `style="background-color:{{item.bg}}"`）、`index.wxss`（`.tab-chip` 深棕描边 + 不规则圆角
  `24rpx 20rpx 26rpx 18rpx` 模拟手绘 + 极淡白色径向高光做笔触质感；选中态缩放+加粗描边，移除旧珊瑚圆气泡）。
- 笔触高光用了 `radial-gradient` —— 是有意偏离"设计系统不用渐变"的例外（仅为满足手绘笔触诉求，非装饰彩渐变）。

  且图标色叠其上（首页选中珊瑚橙 #E05020 ×121 + 近黑 #302010 ×537；其余暖棕 #806050 ×380~600）
  → 底色与图标强对比成立，数据证伪"被背景淹没"。
